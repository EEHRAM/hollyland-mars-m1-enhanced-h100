# Hollyland Mars M1 Enhanced H100

Архив проверенной сборки `eeb2f2ac` на базе версии 2.0.4.7 для **Mars M1 Enhanced H100**.

В этой сборке можно включать отражение слева направо и сверху вниз независимо или одновременно. Владелец проверил быстрое переключение и нормальный цвет на своём мониторе.

Файл прошивки и контрольная сумма находятся в релизе [eeb2f2ac](../../releases/tag/eeb2f2ac).
