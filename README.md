# Hollyland Mars M1 Enhanced H100 — Horizontal & Vertical Mirror Firmware

Unofficial firmware for the **Hollyland Mars M1 Enhanced H100** field monitor. It adds independent horizontal (left–right) and vertical (top–bottom) image flip controls to the lower toolbar. Both can be enabled together to rotate the preview 180°. The build was tested by the owner with a live HDMI 1080p feed.

[Download the .ota firmware](../../releases/download/eeb2f2ac/HLD_15_TX_H100_S2.0.4.7.ota) · [Release and SHA-256 checksum](../../releases/tag/eeb2f2ac)

**Compatibility:** Mars M1 **Enhanced H100** only. Check your monitor model and hardware revision before installing. Build `eeb2f2ac` is based on firmware version 2.0.4.7.

## Зеркальное отражение экрана Hollyland Mars M1 Enhanced H100

Неофициальная прошивка добавляет в нижнюю панель отдельные кнопки отражения слева направо и сверху вниз. Обе кнопки можно включать одновременно. Работа проверена владельцем на живом сигнале HDMI 1080p.
